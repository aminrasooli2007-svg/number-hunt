# 🎯 Number Hunt — Guess My Number

A modern and interactive number guessing game built with **HTML, CSS, and JavaScript**. Test your guessing skills, find the secret number, and try to beat your best score!

## ✨ Features

- 🎲 Random secret number between 1 and 100
- 💡 Instant feedback for higher and lower guesses
- ❤️ Seven attempts per game
- 🏆 Score system based on remaining attempts
- 📈 Best score saved using Local Storage
- 📝 Guess history with visual indicators
- 🔄 New game functionality
- ⌨️ Keyboard-friendly input and Enter key support
- 📱 Responsive design for desktop and mobile
- 🌙 Modern dark UI with purple accents and smooth animations

## 🛠️ Built With

- **HTML5** — Page structure
- **CSS3** — Styling, responsive layout, and animations
- **JavaScript (ES6+)** — Game logic and interactivity
- **Local Storage** — Best score persistence

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

Replace `YOUR_REPOSITORY_URL` with your repository's actual URL.

### 2. Open the project

Navigate to the project folder:

```bash
cd number-hunt
```

### 3. Run the game

Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code for a better development experience.

No additional packages or installation steps are required.

## 🎮 How to Play

1. Start a new game.
2. Enter a whole number between 1 and 100.
3. Read the feedback to determine whether your guess is too high or too low.
4. Find the secret number within seven attempts.
5. Earn more points by winning with more attempts remaining.
6. Try again and beat your best score!
